Set up Back Tap

iPhone

Create a shortcut once, then use Double Tap to capture readable payment screens and send recognized text to PY’s Wallet.

1 · Create the shortcut

Tap below to open Apple Shortcuts. Tap + to create a new shortcut named PY’s Wallet Capture.

2 · Add these actions in order
  1. Take Screenshot
  2. Extract Text from Image — use the screenshot from step 1
  3. URL Encode — encode the extracted text
  4. Text — paste the URL template below, then replace ENCODED_TEXT with the URL Encode action’s variable (not literal text)
  5. Open URLs — use the Text action output
https://pykhong-a11y.github.io/purple-wallet/?ocr=ENCODED_TEXT

Shortcuts variables must be inserted using the variable picker. Pasting the template alone will not pass payment details.

3 · Assign Double Tap

Open iPhone Settings → Accessibility → Touch → Back Tap → Double Tap → select PY’s Wallet Capture.

4 · Test with a sample

Test on a non-sensitive sample payment screen first. Recognized payments may be saved automatically, so check the result and your account balance afterward.

This is a guided manual setup, not a one-tap shortcut installation. A bank can block screenshots. No screenshot is silently read from Photos, and the shortcut may require permissions or foreground interaction. Never share banking passwords or account numbers.

Backup & privacy

Your data is saved on this device. Automatic cloud backup is not yet connected. Export a backup regularly and save it to iCloud Drive or another safe location.

Restore replaces all current PY’s Wallet data. This app does not connect to banks or Apple Pay, and does not ask for banking passwords.

Home Screen widget

Export only monthly totals (no account details or transaction list). Save the downloaded pys-wallet-widget.json in iCloud Drive → Scriptable. Your Scriptable widget will show this snapshot until you export it again.

Install on iPhone

Once hosted on HTTPS, open the site in Safari → Share → Add to Home Screen → Add. The app then works offline after its first successful load.
